# Codex

A Claude Code hook system that automatically documents code as it is written and summarises sessions on exit.

## What It Does

**While you work** — every time Claude writes or edits a file under `src/`, a companion explanation is generated at `.codex/src/<filename>.md`. It describes what the file does, why it exists, what it protects against, and what invariants it maintains.

**When the session ends** — a session summary is written to `.codex/sessions/YYYY-MM-DD.md` covering what was built, decisions made, and open questions.

Both are generated by calling the Anthropic API (Haiku) from hooks wired into Claude Code.

## Requirements

- Python 3.7+
- Claude Code installed
- `ANTHROPIC_API_KEY` exported in your environment

## Installation

```bash
git clone https://github.com/Big-Bronson/Codex.git
cd Codex
python install.py
```

The installer:
- Copies hook scripts to `~/.claude/hooks/`
- Merges hook configuration into `~/.claude/settings.json` without overwriting existing settings
- Installs `CLAUDE.md` teaching rules to `~/.claude/CLAUDE.md` (backs up any existing file)
- Patches hook commands with the correct Python binary and absolute paths for your platform
- Reports a pass/fail checklist

Safe to re-run — it will not duplicate hook entries.

## Project Setup

Each project that uses Codex needs:

1. A `src/` directory — hooks only fire for files written here
2. Git initialised — hooks use `git diff` to extract what changed
3. A project-level `CLAUDE.md` describing the project

```bash
cd my-project
git init
mkdir src
```

## Output Structure

```
my-project/
├── src/
│   └── service.py
└── .codex/
    ├── src/
    │   └── service.md       ← auto-generated explanation
    ├── sessions/
    │   └── 2026-05-12.md    ← auto-generated session summary
    └── codex.log            ← append-only write log
```

Commit `.codex/` with the project so explanations travel with the code.

## Per-Project Configuration

By default the hook watches `src/`. To point it at a different directory, create `.codex/config.json` in the project root:

```json
{
  "src_root": "Public"
}
```

The hook reads this at runtime. No reinstall needed. If the file is absent, `src/` is used.

## Files

| File | Purpose |
|------|---------|
| `install.py` | Installer — run this |
| `codex_post_tool_use.py` | PostToolUse hook — generates per-file explanations |
| `codex_stop.py` | Stop hook — generates session summaries |
| `settings.json` | Hook wiring template (merged into your settings by the installer) |
| `CLAUDE.md` | Global teaching rules installed to `~/.claude/CLAUDE.md` |
